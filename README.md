# S2U STARBOARD — 星空掲示板

紺色の星空をテーマにした、Hearts2Heartsファン向け非公式交流掲示板のフロントエンド試作です。

## 現在実装されている機能

- 星空背景のアニメーションと星のマップ
- 投稿（ニックネーム、メンバー別カテゴリー、180文字以内）
- 日替わりお題
- メンバー別フィルター、検索、並べ替え
- 星のマップから投稿詳細を開く
- 共感・ハートのリアクション
- 投稿への返信
- シェア文のコピー／端末共有
- 星空の投稿数・進捗表示
- ニックネームの保存
- レスポンシブ表示、動きを減らすOS設定への対応

## 起動方法

1. ZIPを展開する。
2. `index.html` をブラウザで開く。またはフォルダ内をGitHub Pagesなどの静的ホスティングへ配置する。
3. ブラウザ上で投稿・返信・リアクションを試す。

ビルドツールは不要です。HTML/CSS/JavaScriptだけで動作します。

## 大切な制限（現段階）

これは**フロントエンドのデモ版**です。投稿・返信・リアクション・ニックネームは `localStorage` に保存されるため、同じブラウザ内でのみ保持されます。別の人の端末と投稿を共有することはできません。デモ投稿も最初の表示確認用です。

全ユーザーでリアルタイムに投稿を共有する公開版にするには、Firebaseなどのバックエンド接続が必要です。公開前には、認証、データベースのセキュリティルール、投稿のレート制限、通報・ブロック・削除の管理機能、プライバシー方針を実装してください。現状のデモ版を、そのまま公開された共有SNSとして扱わないでください。

## ファイル構成

- `index.html` — 画面構成
- `styles.css` — 星空デザイン、レスポンシブ、アニメーション
- `app.js` — 投稿、返信、リアクション、星マップ、ブラウザ内保存
